# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### How to Report

- **Email:** security@ashishagarwal84.github.io
- **Do NOT** open a public GitHub issue for security vulnerabilities.

### What to Include

- A description of the issue
- Steps to reproduce
- Impact assessment
- Any proof of concept (if available)

### Response Timeline

- We will acknowledge receipt within 48 hours
- We aim to provide an initial assessment within 5 business days
- Critical issues will be addressed as soon as possible

## Supported Versions

Only the latest version of the project is actively maintained for security updates.

## Scope

This policy covers the codebase of this repository. It does not cover:
- Third-party dependencies (report to the respective maintainers)
- Issues in external services or platforms
